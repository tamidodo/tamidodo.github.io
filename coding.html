Meteoroid origin classification pipeline

An N-body simulation pipeline built on REBOUND/REBOUNDX that reconstructs the orbital histories of observed meteors, including radiation-pressure and gravitational forces, and derives probability distributions over ejection times to classify each meteoroid as asteroidal or cometary.

Luciole satellite-tracking dashboard

A public-facing web application (built with Plotly/Dash and a Postgres database backend) displaying nightly megaconstellation satellite detections over Canada: network-wide detection counts and brightness statistics, an interactive map of ground tracks, and mosaic views of the stacked raw images.

Meteor Physics Group data infrastructure

"Plug-and-play" data pipelines and Postgres databases for the Western Meteor Physics Group, with reusable interfaces that let researchers load, sync, and query large observational datasets without bespoke wiring each time. These are internal dashboards for WMPG use only.

Python

Apophis close-approach simulations

High-fidelity REBOUND/REBOUNDX simulations sweeping a range of post-2029-flyby scenarios for 99942 Apophis, evaluating the close-approach's effect on the Yarkovsky effect strength acting on the asteroid and recomputing the gravitational keyholes that govern future impact risk.

Semi-automated insurance data pipeline

An end-to-end data-processing pipeline on Google Cloud Platform: BigQuery for storage, Cloud Functions for automated cleaning, Pub/Sub for triggering, Data Studio for dashboards, and Cloud Logging for notifications, with Flask/HTML for embedding visualizations and data tables in a web app. This is a private client project, not accessible on Github.
